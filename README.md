# Warmup Control Center — Milestone 1

This workspace contains a TypeScript Node backend scaffold implementing Milestone 1:

- Authentication (signup/login)
- MailWizz connection model + API endpoints
- MailWizz delivery-server sync service (getDeliveryServers)
- Mailbox model and listing endpoint

Run:

```bash
npm install
cp .env.example .env
# edit .env to set MONGODB_URI
npm run build
npm start
```
